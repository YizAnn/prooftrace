# 寻证 ProofTrace · P8 Creative Workspace

版本：2026-11-21 · UI 集成迭代

这是从 **P7.2 实际业务代码** 增量改造的可运行网站。外观采用 Concept Studio v1 的 Evidence Field 方向。保留原版前端状态与评分实现、服务器 / Agent、北京企业正式名录、人工采信和专家规则。数据与功能来源均见对应源码，原始 `index_p72_backup.html` 保留备查。

## Windows 一键启动

1. **解压完整 ZIP**，不要只单独提取 HTML 文件。
2. 双击根目录 **`启动ProofTrace.cmd`**。需要已安装 Node.js 18+。
3. 启动脚本扫描 8787–8806 端口并打开 `http://127.0.0.1:<端口>/`。P8 服务版本为 4.4，避免误复用 P7.2 的旧服务。
4. 首页可切换 `01 / FIELD` 与 `02 / TYPE`；点击 **进入研究工作区** 或 **探索研究工作区** 自动以本地体验账号进入企业画像。
5. 如需真实 AI：页面左下角 **配置 AI 模型**，或者在 AI 栏中配置百炼 API Key。密钥由原版安全代理验证并存储，**不要放进代码、聊天、截图或提交包**。

> 单独双击 `index.html` 可以查看部分离线内容，但真实 Agent / AI 解析必须通过上述 Node 本地服务才能访问同源 API。

## P8 改动

- **首页**：复用 Concept Studio 的互动 Canvas 证据场、实验排版、两种视觉方案。
- **导航**：11 个原业务页面整理成五个工作领域：发现企业、企业研究、证据中心、技术评价、交付管理。每个业务页面仍可访问。
- **企业研究**：保留完整 P7.2 企业画像，增加轻量研究头部、真实卷宗指标摘要、一行输入直接发起原版 Agent 请求。AI 打开后沿用原版会话记录、工具执行记录、引用、提案人工确认和错误反馈。
- **证据中心**：用当前卷宗的 `evidences` 列表动态创建可点选图谱；点击节点查看来源、分级、时间、状态；一键切到原版完整台账和人工采信面板。原版证据搜索、等级筛选、原文片段、引用来源与冲突处理没有删掉。
- **技术评价**：增设五维指标概览、实际证据数、充分度和正式出分状态；原版评分算法、门槛、专家规则编辑、版本与影响预览仍由原版业务层负责。
- **减法**：原版常驻 11 条侧边菜单变为按领域展开；原版常驻右侧判断栏收起，保留业务内容在企业画像和评分页；AI 按需打开，主区获得更大空间；取消在进入真实企业工作区时自动生成新的合成演练样本提示。
- **视觉**：统一暖白、朱红、银灰和线网母题，减轻卡片圆角/阴影，增加栏目转换、悬停与轻量动画；保留降低动态效果偏好的适配。

## 推荐验收顺序

1. 首页 → 企业研究 → 打开 AI Agent，验证连接状态、问答、工具调用和记忆（需要自有 Key）。
2. 证据中心 → 点节点 → 完整台账 → 证据详情 → 人工标记（使用独立测试数据或注意避免污染真实卷宗）。
3. 技术评价 → 五维状态 → 原版评分明细 → 专家规则 → 查看影响预览。请先查看测试结果再发布规则。
4. 发现企业 → 北京名录 → 搜索、选择企业、建卷；确认今日待判没有合成苏州/上海记录。
5. AI 解析 → 粘贴材料 → 运行抽取 → 人工逐条确认后导入。
6. 导出交付 → 生成并下载；验证不同岗位权限。
7. 在 1280 / 1440 / 1920 分辨率、移动端与视频录制尺寸检查布局。

- P8 服务 `server/server.js` 只新增首页 `home.html` 的静态白名单，仍仅监听 `127.0.0.1`，非本地监听需额外鉴权。
- P7.2 原业务 HTML 保留在 `index_p72_backup.html`，可以比较具体改动。
- P8 UI 与原业务还共存于单文件中，后续需要将样式与页面逐步模块化以便团队协作。
- **当前属于功能回接后的第一个整合版本**。它的下一阶段重点是减少业务内容自身的冗余、将证据图谱接上技术声明多层关系、进一步设计真实 AI 执行时的过渡与可视化。
