# ProofTrace P8.6 — 旧版首页的艺术重构

## 本版如何融合
- **首页内容和工作方式：** 以指定的 `index(5)(1).html` 旧版 Home Page 为基础，保留四步自动播放及手动切换、证据样例、交互式历史规则评分等完整演示。
- **视觉设计：** 引入 P8.5 的「技术，怎么打分？」巨型排版、交互式曲面、红白双主题、连续品牌文字带。原有模块以暖白、朱红和编辑式字体统一重新排版，新的 AI 研究区可切换三项问题。
- **产品数据：** 新首页的真实企业部分使用已接入的北京 6,190 家企业名录和中科艾科米卷宗；旧的 2,480 家合成样本与 79 分/B+ 评分仅在标注清楚的“历史交互演示”里出现。
- **工作区：** `index.html` 为最新 P8.5 工作台，企业名录、Agent 21 工具、证据核验、技术评价、规则和导出代码均保留。旧首页内部的登录与工作区被隔离禁用。

## 入口路径
- 首页点击登录，进入最新登录界面。
- 首页点击带业务目的的按钮，登录后进入对应的新版页面。进入寻证 AI 会自动展开 Agent。
- 本项目采用 `index.html` 加两个首页展示文件 `home.html`、`hero_visual.html`，请保持文件相对路径。

## 测试
- Chromium 通过静态 HTML 浏览器渲染与交互测试（内联资源方式）：主题切换、原版四步切换、AI 示例问题切换、桌面及 390px 窄屏、登入新版工作台后的 Agent 展开。未见脚本错误与页面横向溢出。
- Agent 契约、Agent 运行时、研究评分、启动脚本共四组原业务自动测试通过。
- 真实百炼 API 在线调用尚未在本测试环境执行，请在配置 Key 的本机检查。

## 启动
解压后运行 `启动ProofTrace.cmd`，Node.js 18+。请保留 `data`、`server`、`tools` 文件夹。
