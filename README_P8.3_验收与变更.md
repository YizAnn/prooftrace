# 寻证 ProofTrace P8.3 · 视觉及内容精修

## 本轮修改

1. 保留 Evidence Field 首页，并增加可点击的四段研究工作流展示；各环节跳转真实工作区对应页面。
2. 删除侧边栏重复品牌标识，顶部原 Logo 可返回首页。
3. 工作区状态颜色统一为朱红、暖灰和陶土色，文字标签保留状态含义。
4. 重新设置北京企业名录、今日待判、技术评价、证据充分度的独立列宽，修复偏移与长文本换行。
5. 待核证据“去判定”按钮禁止折行；公式居中并保留完整计算过程。
6. 报告预览采用适应 A4 的自适应列宽与中英文换行规则，压缩重复解释性文案。
7. 保留 P8.2 的 AI Agent、资料解析、证据采信、评分引擎和专家规则代码。

## 验收边界

- 本轮没有修改评分公式、证据等级与真实 AI 请求协议。
- 首页的交互演示基于已有公开案例卷宗，点击按钮进入真实业务页面。首页并不自动调用大模型。
- 报告按照内部技术研究材料的结构精修；尚未获得银行正式行内格式模板，不能声称已符合具体机构的内部规范。
- 百炼真实 API 仍需在装有密钥的本机环境验收。

## 启动

Windows 解压后双击 `启动ProofTrace.cmd`，需要 Node.js 18+。原始 P7.2、P8 备份仍保留。
