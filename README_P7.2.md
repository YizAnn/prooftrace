# 寻证 ProofTrace P7.2

北京科技企业技术价值尽调工作台。本版本在 P7.1 稳定版上完成 Agent 稳定性、一键启动与安全密钥、北京真实数据统一、专家规则入口、页面精简与排版调整。

## 快速开始

1. 双击 `启动ProofTrace.cmd`。
2. 脚本会检查 Node.js、扫描 8787–8806、跳过旧版本服务、启动当前版本并打开浏览器。
3. 首次使用点击页面右上角“配置模型”或 Agent 右栏的“配置模型”，由本人填写百炼 API Key。
4. Key 先做一次最小真实校验，通过后用 Windows DPAPI 加密保存；之后启动自动读取。

当前版本：服务 4.3 / Agent 1.3。默认只监听 `127.0.0.1`。

## 安全

- API Key 不写入 HTML、localStorage、源码、日志、聊天记录或交付 ZIP。
- 非本机监听必须设置 `PROOFTRACE_AUTH_TOKEN`，否则服务拒绝启动。
- 默认限流 240 次/分钟，CORS 仅允许本机来源与 `null`。
- 正式证据采信、评分确认、规则发布、业务档案覆盖仍需人工确认。

评分结果需人工复核，不构成授信意见。
